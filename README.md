# EduTrack

EduTrack is a web-based application designed to provide a comprehensive overview of a student's academic performance and school-related activities. It features a clean, user-friendly interface for tracking grades, attendance, and behavioral notes.

## Features

- **Student Information:** Displays basic information about the student, including name, grade level, and date of birth.
- **Academic Performance:** Shows the student's current grade in a specific subject (e.g., English) and tracks their performance trend over time with a visual graph.
- **Teacher's Notes:** Provides a dedicated section for teachers to add notes and comments on the student's performance.
- **Attendance Tracking:** Includes an attendance rate summary with a progress bar, showing the number of present days out of the total school days.
- **Behavior Summary:** Summarizes positive and negative behavior instances noted by teachers, along with communication records with parents.

## Technologies Used

- **HTML5:** The core structure of the web page is built with semantic HTML.
- **Tailwind CSS:** The application is styled using the Tailwind CSS framework for a modern and responsive design.

## How to Run

To view the page, simply open the `index.html` file in a web browser.
